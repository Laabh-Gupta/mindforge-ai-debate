2. Current development philosophy

The application originally contained a lot of demonstration/mock data.

The goal now is:

Anything presented to the user as their progress, score, history, activity, streak, sessions, XP, etc. should eventually represent actual data generated by their usage of the application.

We do NOT want fabricated values such as:

62 debates
81 communication score
12-day streak
27.5 hours practiced
4,820 XP
Level 8
"2 of 3 sessions complete"

for a brand-new user.

A new user should start from an appropriate zero/empty state and have those values increase as they actually use the application.
